
# Civitas — Docs

Documentation for the Civitas project. Lives in `docs/` and publishes to [GitHub Pages](https://pedropcamellon.github.io/civitas/).

## Files

| File                                   | Audience            | What it covers                                 |
| -------------------------------------- | ------------------- | ---------------------------------------------- |
| [index.md](index.md)                   | Everyone            | Landing page — what the app is, where to start |
| [motivation.md](motivation.md)         | Everyone            | Origin story, UX philosophy, MVP decisions     |
| [user-guide.md](user-guide.md)         | End users           | Map, layers, time filter, panels               |
| [infrastructure.md](infrastructure.md) | Developers          | Docker, Vercel, deployment, data pipeline      |
| [open-data.md](open-data.md)           | Developers / agents | Ingest pipeline, data sources, field mappings  |
| [web-migration.md](web-migration.md)   | Developers          | Mobile → web port phases and constraints       |

## Doc conventions

- No code snippets — intent and decisions only
- No numbered headers — use descriptive titles
- One topic per file — split before it grows long
- Store data source findings — quirks, field names, endpoint behavior belong here as permanent learnings
- Status markers on every page: `✅ Done` · `🚧 In Progress` · `📐 Specified`
