🧭 Project Spec: “Civic Flow Miami”

A lightweight mobile-first web app that visualizes Miami / South Florida civic data (crime, transit, permits, flooding, etc.) on an interactive map with simple UX over GIS dashboards.

Built for:

* residents
* researchers
* journalists
* curious users

Focus: “What is happening near me?”

⸻

🎯 Core Product Idea

Turn messy public datasets into a simple map-based experience:

* “What’s happening near this location?”
* “What changed in my area recently?”
* “What risks / services exist around me?”

No dashboards. No PowerBI feel.

Just:

* map
* filters
* timeline
* simple insights

⸻

🧱 Tech Stack (cheap + vibe coding friendly)

Frontend (mobile-first)

* React or Next.js
* TailwindCSS
* Leaflet.js via Folium (optional Python mode) OR direct Leaflet

Backend (minimal)

* Serverless functions OR FastAPI
* No heavy infra needed

Hosting

* Vercel / Cloudflare Pages (free tier)

Data storage

* Start: static JSON (important for MVP)
* Later: SQLite or Postgres + PostGIS if needed

📊 Data Pipeline (simple version)

Step 1: ingestion

* pull Socrata APIs (JSON/CSV)

Step 2: normalize

Convert everything into:

{
  "id": "",
  "type": "crime | permit | 311 | transit",
  "lat": 0,
  "lon": 0,
  "timestamp": "",
  "metadata": {}
}

Step 3: cache

* store as JSON files or SQLite

Step 4: serve

* static API endpoint or direct frontend fetch

🧠 UX Philosophy (important)

This app is NOT:

* GIS dashboard
* analyst tool
* PowerBI clone

It is:

“Google Maps, but for civic activity”

Rules:

* max 2 clicks to insight
* no tables
* no raw datasets
* everything must be map-first

⸻

📱 Mobile-first constraints
